01 / Pipeline de Captura

Como o Mpdownloader Funciona

3 Etapas Automatizadas
01 · Extração DOM

Mapeamento Inteligente

Analisa o HTML, folhas de estilo, scripts, favicons, atributos srcset e imagens com lazy loading (data-src).

02 · Sub-recursos CSS

Fontes & Backgrounds

Varre cada arquivo CSS para capturar fontes .woff2/.ttf de @font-face e imagens referenciadas em url(...).

03 · Empacotamento

ZIP Pronto p/ Offline

Reescreve todas as URLs para caminhos relativos em assets/ e entrega um .zip pronto para abrir sem internet.

02 / Uso do Pacote

Como Abrir o Site Baixado

Duplo Clique ou Servidor Local
Opção A · Mais Simples

Duplo Clique no Navegador

Extraia o arquivo .zip baixado e dê duplo clique em index.html. Ideal para guardar referências de UI, portfolios e landing pages estáticas.

Sem terminal · 100% offline
Opção B · Sites Dinâmicos

Servidor Local em 1 Comando

Para sites com módulos JS modernos, abra o terminal na pasta extraída e execute um dos comandos abaixo:

$ npx serve .
# ou com Python:
$ python -m http.server 8080
